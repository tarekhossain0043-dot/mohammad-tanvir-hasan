# Mohammad Tanvir Hasan Tarek — Portfolio

A polished, responsive single-page developer portfolio built with **Next.js 14, React, TypeScript, Tailwind CSS, GSAP, and Lucide React**.

## Features
- Responsive single-page layout with About, Expertise, Work, Experience, and Contact sections
- GSAP entrance, scroll-triggered, parallax, and continuous hero animations
- CSS 3D orbital hero visual
- Custom cursor on fine-pointer devices, with touch-device fallback
- Reduced-motion accessibility support
- Project links, GitHub, LinkedIn, email, phone, and WhatsApp contact links

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
npm start
```
